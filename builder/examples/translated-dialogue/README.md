# Partial Ancient translations

Original Ancient dialogue for [the dialogue contract](../../DIALOGUE.md). Copy `dialogue.json` to a character project and enable `features.dialogue` before validating/generating.

The first Neow conversation has partial French/Japanese text and labels. Empty objects intentionally retain English fields, speakers and default Continue labels. The repeat conversation stays English-only. This sample demonstrates routing and fallback; it is not human translation/font/layout approval.

Every changed character project requires its own current native evidence. Victory/ending dialogue and voiced lines remain outside this contract.
