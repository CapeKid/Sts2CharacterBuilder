# A Sheltered Crossroads

Original bounded solo event example for [the event contract](../../EVENTS.md). Copy `events.json` into a character project and enable `features.events` before validating/generating.

The initial choice leads to Camp or Trail; both can lead to Shelter. Terminal Trade choices deliberately reuse their ID on separate pages to demonstrate page-qualified localization and evidence. Only terminal choices charge resources or grant rewards. Leave is available on every page. A checkpoint reload restarts at INITIAL.

The costs/rewards demonstrate the contract; they are not a balance approval or campaign observation. Native imagery remains an explicit placeholder.

The sample and a legacy event passed a fresh owned v0.111.0 fixture; see the [native receipt](../../../docs/branching-events-native-fixture.json). Other character projects require their own current native evidence.
