---
name: create-character-art
description: Prepare supplied, generated or original placeholder card and UI art with provenance.
---

Ask whether custom art is wanted, collect supplied images, then ask whether to fill missing art. Match the character's approved style and preserve source files.
Use available generation tools only within budget/authorization. Without them, use clearly labeled original placeholders. Never extract or distribute game imagery.
Every shipped asset must be listed in assets/manifest.json with project-relative path, SHA-256, method, license and credit. Hash declarations are records, not proof of rights. The minimal template reads assets/icon.svg and assets/card.svg from its DLL directory; additional per-card art requires a project-owned portrait override. Adding an unused file does not complete integration.
Validate SVGs, raster dimensions/crops and in-game appearance. Review card art at actual UI size and character icon readability. Keep any source metadata out of shipping files when inappropriate.
Skip outcome: retain the original visible geometric placeholders for required art; record the unfinished art in delivery notes.
