description: Guide or resume creation of a standalone Slay the Spire 2 character using this toolkit.

Read [the workflow](../../WORKFLOW.md) and the project's character.json. If this is a new idea, use setup-character-project. Reuse details already given.
Ask whether to use guided or expedited authoring only when the request does not establish it. Guided mode asks short groups as each stage arrives; every creative question offers “choose for me”. Expedited mode uses the supplied idea, fills creative blanks, records assumptions, and continues without a questionnaire. Neither mode authorizes paid services or publication by itself.
Run resume before authoring. Follow setup → mechanics → cards → art → items → events → dialogue → sprites → presentation → audio → verification → balance → publication preparation. Read the named skill as each stage is needed. A disabled optional feature is skipped with its documented fallback. AI delegation enables the feature; skipping disables it. Never conflate these.
Record decisions in character.json choices, including user ideas verbatim where useful. Respect supplied cards/assets; ask whether to fill missing content. Bootstrap defaults are a small prototype, not completion of an idea-only request. Continue adapting the character to the idea, finish authorized modules, and report actual gaps.
Use record for evidence-backed progress. A changed input invalidates prior completion. Never mark a step complete based solely on this skill having been read.
