description: Prepare and integrate character sprite states, anchors and room presentation.

Ask whether sprites are wanted, collect references/supplied frames and offer AI completion. Agree on style and proportions. Use image generation only with an available authorized tool; otherwise keep disclosed native placeholder presentation.
Create project-owned assets for idle, attack, skill, hurt, death and victory plus rest/shop variants as needed. Record atlas dimensions, frame rectangles, anchors and scale; test scene transitions and seek/reset behavior. Ensure no frame is cropped at 1280x800.
The baseline PlaceholderCharacterModel intentionally uses native runtime placeholder sprites. A new atlas must be wired through project-owned presentation code before it replaces that fallback. Files alone do not complete this stage.
Output sprites, provenance and visual/native evidence. Skip outcome: sprites false; native placeholder animation remains visible and disclosed.
