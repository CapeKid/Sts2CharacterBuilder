---
name: create-character-events
description: Author optional character-specific events and test their registration and outcomes.
---

Ask whether events are wanted, collect all ideas, and offer AI completion separately. For supported solo events, author design/events.json using [the event contract](../../EVENTS.md): act positions, title/body, choices with bounded Gold/HP costs and Gold/healing rewards, and terminal result text. Optional pages form a reachable acyclic graph of at most eight pages including INITIAL; navigation uses next with zero costs/rewards. Shared destinations are allowed. Optional requires predicates combine inclusive Gold and HP-percentage ranges without charging resources; callbacks recheck them before acting. Leave is added automatically. Native event imagery is an explicit runtime placeholder. Other layouts, arbitrary predicates/effectful navigation, combat, card/item rewards and custom effects need project-owned src/Extensions implementations against the selected branch's actual API.
Specify encounter eligibility, choices, costs, rewards, unavailable-choice text, re-entry and save behavior. Use explicit character predicates so unrelated characters are unaffected. Record co-op policy only if supported and tested.
Run validate, generate, build and a fresh isolated native suite. The suite checks act/character/solo eligibility, visible choices, resource/cost thresholds, each authored condition's boundary and stale-state controls, duplicate/old-page selection, every page's Leave, and the game's pre-choice checkpoint/after-leaving save behavior. Branch position resets to INITIAL at a checkpoint reload. Human visual/controller review and multiplayer behavior remain separate. Do not claim arbitrary mid-callback saves are supported transactions.
Output authoring data, generated models/localization and native evidence. An enabled flag with no data remains a gap. Skip outcome: clear design/events.json and set events false; no added event registration. Preserve frozen Event_ model IDs during upgrades or provide an explicit migration.
