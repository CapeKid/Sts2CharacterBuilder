Run validate, generate --check, test and build as described in [the workflow](../../WORKFLOW.md). Record toolkit/project revision, source/input/DLL hashes, game branch/build and dependency versions. The structural report always distinguishes native gaps.
Exercise native selection, starter deck/relic, new card base/upgraded values, new power/resource, turn flow, targeting, card disposal, reward/shop/compendium and save/resume on each claimed branch. Test disabled features and malformed inputs. Custom effects require specific expected outcomes, not a loop that merely instantiates cards.
Use prepare-lab and test-native from [native testing](../../NATIVE-TESTING.md) for the generated numeric fixtures. These create independent copies, a dedicated profile, disabled Workshop mods and a replaced save backend; each lab runs only once. Read the emitted evidence and actual coverage. Authored Architect endings need both dialogue and completion records: real closing attacks/WinRun, exactly-once score/stat/history processing in the isolated backend, checkpoint removal, post-win character/result and native menu return. Confirm the test-only platform isolation is installed before invoking an ending; a mocked save backend alone does not isolate the shared Steam statistic or telemetry. Keep forced-ending fixtures distinct from campaign reachability/balance. Native code is excluded from normal packages. Keep the imported reference-mod launchers out of this workflow.
For independent reproduction, follow the fresh recursive-clone and skipped-content trials in that reference. Use the clone's remotely pinned CLI without copying ignored builds/profiles/helpers. A fallback sentinel is not an executed custom-feature test. Keep native receipts separate for each identity/configuration, and disable optional models only before their first build or through a reviewed migration.
Output project-relative evidence and record each completed stage. Physical Deck, online co-op, unavailable branches and unsupported effects remain named gaps. Do not mark release-ready while essential gaps remain.
